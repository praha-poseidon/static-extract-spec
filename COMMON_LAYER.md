# Common layer boundary

## This package owns

- SER structure grammar and skeleton semantics  
- JSON schemas for facts, rule IR, vocabulary **manifest shape**  
- Abstract CLI command list  

## This package does not own

- Any language runtime (JDT, ts-morph, …)  
- Any language vocabulary catalog or framework recipes  
- Language-specific examples or agent skills  

Those belong in `static-extract-java`, `static-extract-js`, or future extractors.
